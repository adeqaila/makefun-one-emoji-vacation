One emoji for a dream vacation: a single palm tree (🌴, U+1F334) — a tropical beach postcard at a glance, chosen after an 8-candidate pairwise tournament under the house judge's brief, where it won its quarter-final 0.80 and semi-final 0.75 with all judge calls agreeing.

Entry: exactly one emoji, 1 character, 4 bytes UTF-8. Run `python3 main.py` to write it to `/output/entry.txt`.
